# Discovery beta evaluation

This directory contains the **prepared** blinded evaluation protocol and
collection scaffolding for TJ-027/TJ-028/TJ-029.

- No participants have been recruited.
- No scores, summaries or release evidence exist.
- The candidate is **HOLD**; external evaluation and live supported-model proof
  are **BLOCKED**.
- Do not publish, release or claim beta validation from these templates.

| File | Purpose |
|---|---|
| `protocol.md` | Fixed design, thresholds, blinding and analysis rules (TJ-027) |
| `consent.md` | Participant consent template |
| `paired-request-template.md` | Per-participant two-request record |
| `scoring-rubric.md` | Operational definitions and 1–5 anchors |
| `calibration-example.md` | Non-scored reviewer calibration example |
| `freeze-manifest.json` | Candidate/model/prompt freeze template (unfilled) |
| `collection/` | Import headers, anonymization and analysis templates (TJ-028) |
| [`planning-pilot/`](planning-pilot/README.md) | TJ-033 Planning pilot protocol and handoff/feedback templates; **external validation BLOCKED**, no participants |

The local scripted TJ-026 browser suite proves software behavior only. It is not
a participant study and cannot supply product-evaluation or live-provider
evidence.
